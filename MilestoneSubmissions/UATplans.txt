Registration Page
  Test Scenario
    User is redirected to login page after registration
    Test Cases:
    Username:abc
    Password: 123
    First Name: Homer
    Last Name: Simpson
    Email: email@gmail.com
    Date of Birth: 01/01/2000

  Test Environment:
    To test our login page direct yourself to http://localhost:3000/register
    Expected Test Results:
      When a user successfully register’s it will direct them to the login page. If they do not enter a valid username, password, first name, last name, email, and DOB then        they will be prompted with an error message. 

  Testers:
    2 team members, 2 team members who are not the primary developers of the registration feature. Ideally, one technical user and one non-technical user to simulate real        user   behavior. Will check different variations of complete and incomplete fields.

Movie Discover Page
  Test Scenario
    User can browse the discover page to see a list of several movies, their rating, and description
  Test Case
    Logged in user
    Logged-in user: Any registered user with valid session
    API: TMDB API (requires valid API key in .env file)
    Expected movie count: At least 10-20 popular movies
  Test Environment
    Local Host (https://localhost:3000)
  Testers:
    2 team members, who didn’t develop the discover page can properly browse it and explore the movie catalog
  Expected Test Results
    The user logs into their account and is directed to the discover page immediately, the page shows movies with names, image of posters, rating, and genre, and they are        displayed in an orderly and well designed manner.
