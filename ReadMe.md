MatchFlix makes picking a movie to watch more fun. You can browse a discover page filled with movies and add them to your watchlist, or you can use our swipe feature to dislike and like movies, after liking a certain amount of movies our reccomendation algorithim will give the user some movies they should watch.

Contributers: Bhargav Sairam, Ryan Fayock, Karson Kelley, Aswaanth Karuppasamy, Charlie Guo, Neville Jijina

Technology Used for the project includes: GitHub, PostgreSQL,VSCode, Figma, NodeJS, Render, TMBD, Gemini, Mocha, Agile

Prerequisites to run the application: You need VSCode as well as docker to run our project. Before docker compose up, run npm install, then docker compose up, and check your localhost and you will be able to access it locally

How to run the tests: To start first run "npm install mocha chai chai-http", then run "npm test", the js file for testing has already been provided
